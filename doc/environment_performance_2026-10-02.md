# Профиль окружения, 2026-10-02

Пользователь остановил собственные замеры: дальнейшее профилирование выполняет параллельная сессия Claude. Чистого сравнения после правок пока нет; улучшение FPS не заявляется.

## Измерено до правок

Инструмент: `tools/campfire_profiler.py`, xctrace Time Profiler и короткий Metal System Trace. Mac M3 Pro, 18 ГБ, RelWithDebInfo, диагностика/внутренний профайлер выключены. Мир average, seed 11, позиция 228608,28928, 1600 × 1000; качество и маршрут сохранены рядом с трассами.

Это маршрут со стримингом; ограничение начальной загрузки 900 кадров достигнуто до полного завершения. В неподвижном лесу после заполнения — примерно 38–42 FPS.

### Причины

- На маршруте `WorldSnapshot::scatter` — 125.64 с из 310.54 с суммарного CPU всех потоков (40.46 %). Высоты, уклоны и материалы повторно вычисляются на соседних кандидатах. `__udivmodti4` занимает 20.23 % собственного CPU; это в том числе детерминированная арифметика фундамента и квадратного корня.
- В установившемся лесу перебираются примерно 157 тысяч объектов ради примерно 196 оставшихся. Из 12.99 с CPU захвата `cullToFrustum` занимает 2.66 с, `Horizon::binOf` — 2.04 с, собственно `atan2` — 1.68 с.
- `Device::waitInFlight` занимает 8.32 с того же захвата. Ожидание Metal активно опрашивает atomic; само ожидание не является полезной работой кадра.
- При запуске `loadArrayMipped` занимает 7.78 с CPU; `sizeOf` декодировал изображение перед повторным декодированием для загрузки.
- В Metal-захвате основной мировой render encoder: медиана активного Fragment — 19.25 мс, Vertex — 2.86 мс; Compute encoder — 9.41 мс. Это объединения интервалов внутри одного encoder, их нельзя складывать в длительность кадра. Шейдерная детализация шаблона отключена, отдельный шейдер по этой трассе не установлен.

## Внесено, клиент собран

1. Ограниченный кеш точных lattice-запросов высоты/уклона/материала на время расстановки региона. Учитывает stride, ревизию правок и стадию террейна. Области кеша привязаны к потоку и конкретному полю; копии поля не наследуют кеш. Целочисленная геометрия и seed-правила сохранены.
2. Metal ожидает GPU коротким спящим опросом через `SDL_QueryGPUFence`/`SDL_DelayNS`; число кадров в полёте прежнее. Проверить влияние планировщика на задержку в чистом прогоне.
3. Размеры PNG читаются из IHDR без декодирования; остальные форматы используют прежний IMG_Load.
4. Пространственные группы моделей по 32 м строятся при публикации gather. Консервативные групповые тесты отсекают целые группы, сомнительные группы проходят прежний индивидуальный тест. Порядок объектов/владельцев и причины отсечения сохраняются.
5. Текстурные декали: пропуск при нулевой разрешимости, ограничение соседних ячеек геометрическим радиусом. Влияние переменных границ цикла на GPU ещё требует сравнения.

Одновременно другая сессия меняла публикацию ScenePlacement/SceneEntities по регионам; сохранённый бинарник после правок включает и эти изменения. Не приписывать весь будущий результат одному кешу.

## Артефакты и продолжение

`.cache/profiles/environment-perf-20261002-141509/`: исходный `before-client`, снимки `after-2-client`/`after-3-client`, `before-bench-1.json`, CPU/GPU трассы и HTML, исходные команды, настройки, diff до/после. GPU агрегаты — `gpu-before/encoder-summary.json`.

Прогоны `after-bench-1` и `after-bench-2` недействительны: с ними конкурировали другие клиенты/сборки. У каждого есть маркер `*-invalid.txt`. Свои процессы остановлены, чужие не завершались.

Для продолжения сравнить одинаковые world/config/shaders/cache и маршрут по сохранённой команде; затем снять установившийся лес и короткие CPU/GPU захваты. `before-runtime` содержит восстановленный исходный обход декалей, `after-runtime` — изменённый. При смене рабочей директории явно задать один `ASR_TERRAIN_CACHE_DIR` либо сравнивать одинаково пустые кеши. Нужны прогоны без других клиентов, сборок и xctrace.

SDL: [QueryGPUFence](https://wiki.libsdl.org/SDL3/SDL_QueryGPUFence), [DelayNS](https://wiki.libsdl.org/SDL3/SDL_DelayNS).
