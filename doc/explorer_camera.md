# Камера и диагностика террейна

В GPU explorer (`asr_client --explore`) доступна ортографическая орбитальная
камера. Начальный ракурс сохранён. Это не FPS-камера: вращение идёт вокруг
центра вида, без перспективы и крена; наклон ограничен 10–90° над землёй,
чтобы лучи пересекали heightfield и не требовали бесконечной области загрузки.

| Управление | Действие |
|---|---|
| ПКМ + движение | Поворот на 360° и наклон |
| Shift + средняя кнопка | Альтернативный жест вращения |
| Средняя кнопка + движение | Перетаскивание карты |
| WASD / стрелки | Перемещение в направлениях экрана |
| Колесо | Приближение к точке на плоскости фокуса под курсором |
| Q / E | Поворот |
| Z / X | Наклон вверх / вниз |
| Page Up / Page Down | Смещение высоты фокуса относительно земли |
| Home | Сброс поворота, наклона и смещения высоты |
| I | Инспектор воды и земли под курсором + справка |
| V | Существующая панель погоды |
| F9 | Пауза погоды, удобная для сравнения ракурсов |
| F11 | Показать / скрыть визуальный лёд |

На компактной клавиатуре Mac Page Up/Down обычно доступны как Fn+↑/↓,
Home — Fn+←. В старом SDL explorer Home также возвращает на стартовую позицию.
Открытое меню и потеря фокуса окна останавливают управление GPU-камерой.
Координаты мыши пересчитываются в физические пиксели окна на Retina.

Обратная проекция, глубина, отражения воды и границы загрузки учитывают ракурс.
Зум фиксирует точку на плоскости фокуса, а не делает отдельный terrain raycast.
Инспектор ищет первое пересечение луча с поверхностью земли/воды, затем уточняет
его бинарным поиском; тонкие перекрывающие выступы между шагами луча остаются
приближением. Данные обновляются раз в 250 мс только при открытой панели.

Инспектор показывает:
- dry / river / lake / ocean, уровень поверхности, глубину и coverage;
- downstream-направление (не скорость в м/с);
- полную ширину ближайшего мокрого русла и расстояние до его берега;
- накопленный сток и класс 0–15 **ячейки под курсором** — она может отличаться
  от ячейки-источника извилистого русла;
- местную температуру и потенциал льда из текущей истории погоды. На порогах
  шейдер дополнительно подавляет лёд по уклону; это не точное значение пикселя.

Лёд имеет неподвижный мировой рисунок Вороного с трещинами и многомасштабным
инеем. Субпиксельные детали затухают; текущая рябь подавляется при замерзании.
Непрозрачность льда сохраняет маску берега и не закрашивает сухую часть меша.
F11 отключает также подавление волн льдом, но не меняет температуру, снежный
покров, накопленный сток и гидравлические уровни. Потенциал льда в инспекторе
остаётся климатическим показателем даже при скрытом льде.

## Воспроизводимая проверка

Параметры GPU explorer:
- `--yaw DEGREES` — азимут в градусах, полный оборот; по умолчанию 45°;
- `--pitch DEGREES` — наклон над землёй, ограничивается 10–90°;
- `--focus-height METRES` — смещение высоты фокуса относительно земли,
  ограничивается ±10000 м;
- `--no-ice` — начать со скрытым льдом; F11 возвращает его;
- `--shot FILE` — сохранить кадр после загрузки видимых колец и выйти.

Для сравнения используйте одинаковые `--seed`, `--world`, `--at`, `--zoom`,
`--day`, `--weather` и `--shot-time`, меняя только ракурс или `--no-ice`.
Лог снимка содержит фактические yaw/pitch **в радианах**, смещение фокуса и
состояние видимости льда. Числовые параметры ракурса отвергают NaN/Inf и текст.

Собирайте и запускайте бинарник из одной конфигурации: например, `build-gpu`.
В `build` может оставаться старый `asr_client`, даже если эта конфигурация уже
настроена с `ASR_BUILD_CLIENT=OFF`.
