# Адаптивный terrain: стыки, загрузка и клиентские проверки

Дата: 2026-09-14. Продолжение незавершённой замены регулярной геометрии.
Пользовательские изменения вне этой задачи не откатывались.

## Внесённые исправления

- `TerrainPlan::stitchEdges()` в `terrain_seams.cpp` согласует кромки полного
  сохранённого покрытия, включая невидимых соседей. Дополнительные вершины
  мелкой стороны лежат на сегментах крупной стороны; ограничения разрешаются
  также через общие углы и перпендикулярные рёбра. Поддерживаются разрывы LOD
  больше одного уровня и разные фазы морфинга соседей.
- Земля и вода получают общие высоты. GPU-атрибут `edgeHeight` применяется
  после морфинга, до опускания юбки. Общие точки и опорные концы сегментов
  используют одинаковые CPU float с обеих сторон, без отдельного GPU
  декодирования UNORM на одной из сторон стыка.
- Исходные меши и опубликованные планы не изменяются. Индексы и число
  треугольников при согласовании кромок сохраняются; одинаковые согласованные
  меши предыдущего плана переиспользуются, без повторных GPU-загрузок.
- `TerrainView::refineSurface()` разделяет минимальное качество исходных данных
  и ошибку формы. Нулевое отклонение в H64 больше не считается доказательством
  отсутствия подробностей: масштаб просмотра задаёт минимальный dataset.
  Внутри блока вершины по-прежнему выбирает адаптивная триангуляция, поэтому
  уточнение данных не требует равномерной плотной сетки на ровном склоне.
  Это консервативный предел качества по экранному масштабу, а не доказательство
  ошибки относительно ещё не загруженных высот.
- Критерий используется покрытием, предзагрузкой и индикатором готовности.
  До первого актуального принятого плана, а также при смене камеры/резидентности,
  ожидание больше не равно нулю только потому, что старый список missing пуст.
- Профиль разделяет поверхность, юбки и поданные треугольники воды. Счётчик
  `source-grid-triangles` — регулярная сетка на исходной решётке каждого реально
  отрисовываемого блока. Это явно не замер прежней версии клиента.

## Границы результата

- Ретопология не восстанавливает форму, отсутствующую во всех доступных высотах.
- Проверены математические стыки, GPU-атрибуты и конечные клиентские прогоны.
  Сохранение снимка само по себе не является визуальной проверкой каждого шва.
- Сравнения FPS/памяти с прежним клиентом нет. Ускорение и уменьшение числа
  треугольников относительно прежней версии **не подтверждены**.
  В этой сцене около 762 тысяч треугольников земли плюс 443 тысячи воды —
  абсолютная стоимость всё ещё значительна.
- Готовность к полной замене не следует из двух smoke-прогонов; остаются
  визуальная оценка переходов и сравнительное профилирование старого/нового пути.
