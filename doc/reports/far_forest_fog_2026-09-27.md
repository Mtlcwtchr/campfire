# Дальняя иерархия леса и туман дальности — 2026-09-27

Продолжение [runtime forest proxies](recursive_forest_proxies_2026-09-27.md).
Всё ниже не закоммичено.

## 1. Иерархия (сначала)

### Движок (`Campfire::Impostors`, без SDL/игры)

- `engine/render/impostor_hierarchy.{hpp,cpp}`:
  - ключи 32 → 128 → 512 → 2048 m (`ImpostorKey` получил `level`), 4×4 детей;
  - `resampleImpostor` — coverage-взвешенный даунсэмпл, depth = ближайший
    покрытый texel (никогда не среднее двух поверхностей), view-ID сохранён;
  - `ImpostorStore` — bounded LRU CPU-store (помнит и «пустые» узлы), eviction
    упорядочивает только 32 самых старых;
  - `measureImpostorAgainstChildren` / `withMeasuredError` — ошибка узла
    **измеряется** при bake: из 21 базового и 44 промежуточных направлений
    силуэт родителя (выбор ракурса + dither-вес, как в шейдере) сравнивается с
    тем, что показали бы дети с их собственным yaw/выбором ракурсов;
    99-й перцентиль расстояния рассогласования. Итог монотонен:
    `error = max(total детей)`, `viewError = измеренное`;
  - `selectImpostorHierarchy` — coarse→fine: узел и его потомки никогда
    не выбираются вместе; неготовый узел не скрывает резидентных детей;
    ниже `minLevel` — владение финального пути; бюджет визитов/рисований
    с флагом `budgetLimited`; отсечение «ни один потомок не пройдёт» по
    дальней точке узла (консервативно), и для узлов выше глаза.
- `ImpostorCache::adopt` — готовый атлас в слот без воркера, те же fence/grace
  правила; `ImpostorGpuCache(slots,resolution,budget)` и `upload(device,maxViews)`
  — несколько ракурсов за одну отправку, серийник выставляется после `finish()`.

### Игра (`game::ForestHierarchy`)

- 128 m узел пекётся из **детерминированного scatter** региона
  (`WorldSnapshot::scatter` в воркере), а не из того, что сейчас резидентно в
  placement; 512/2048 m — из детей в store. Revision узла = версия мира +
  хэш правок экологии внутри узла.
- Листья — те же hemisphere-атласы, один раз уменьшенные до 16².
- 96 GPU-слотов 32² (~30 MB), 1/6 слотов резервирована под замену детей
  родителем; 8 ракурсов/кадр; store 96 MiB; 2 фоновых воркера c
  `QOS_CLASS_UTILITY` на macOS; очередь bake: дети перед ждущим родителем.
- Замещение: особи поддерживаемых моделей, 32 m proxy и mass-агрегаты
  в покрытых регионах скрываются только для реально нарисованных узлов;
  регионы с terrain density → `mustRefine`.
- Отбор перезапускается при движении >25 m / повороте / смене дистанции,
  иначе раз в 3 кадра; draw-list каждый кадр перепроверяется по резидентности.
- `ASR_FAR_FOREST=0` — выключить; `ASR_SCENE_DEBUG=1` — счётчики по уровням;
  `ASR_FAR_DUMP=prefix` — PNG первых атласов; `ASR_FAR_DEBUG=1` — состав бейков.

### Измерения (seed 11)

- Обзор `--camera orbit --yaw 0 --pitch 0.3 --zoom 0.6`: средние
  total error L1 ≈ 12 m (measured 6.5), L2 ≈ 48 m (measured 28);
  bake L1 ≈ 10–15 ms, L2 ≈ 4 ms в воркере. Отрисованы 27–33 узла L2 вместо 80 L1.
- Frame-thread стоимость на стандартном маршруте: 0.1–1.9 ms/кадр,
  худший ≈ 3.6–4 ms (было до 19 ms до оптимизаций: линейный поиск
  резидентов, ground-sampling, выбор высоты по умолчанию, eviction sort).
- Маршрут `--bench-load 480 --bench 180`, ON / `ASR_FAR_FOREST=0`
  (mean / p99 / max, ms): orbit 6.35/14.26/17.98 vs 5.59/14.74/16.26;
  forest 5.15/9.20/13.60 vs 4.96/7.79/9.10; остальные сегменты в пределах шума.
  Это не settled A/B.

Честные ограничения: при шаге атласа 32² и измеренной ошибке узлы 128 m
принимаются примерно с 7 km, 512 m — с ~20 km; ближе остаются 32 m proxy и
особи. Широкий ортографический вид целиком не помещается в 96 слотов —
рисуются ближние к фокусу узлы и повышается `pressure` (до ×4), остальное
остаётся прежнему представлению. Переход родитель↔дети атомарный с гистерезисом,
кроссфейда нет.

## 2. Туман дальности (потом)

- `Scene::fog` (+ `fog`/`fogPS` в `world.hlsli`): дистанция, начало (30 %),
  включён. `lookFog` в `landscape_look.hlsli` (общий C++/HLSL) — smoothstep.
- `landscapeFinish` → `landscapeFog`: цвет = `landscapeSky` вдоль того же луча.
  Все мировые шейдеры (terrain, water, models, foliage, sprites) проходят здесь.
- `SkyPass` (`sky.hlsl`): полноэкранный треугольник на дальней плоскости,
  depth test LESS_EQUAL без записи — только там, где ничего не нарисовано;
  после opaque, до blended.
- Слайдер «Draw distance / fog» в статус-панели эксплорера: 2–60 km,
  логарифмический, мышь (захват до отпускания, камера под ним не двигается) и
  `,` / `.` с автоповтором. `--draw-distance`, `--no-fog`.
- Дистанция ограничивает дальний лес и допуск регионов placement.
  Только perspective + Natural; ортографические и инспекционные карты не
  затуманиваются. `camera.farPlane` не меняется (он ограничивает орбиту).
