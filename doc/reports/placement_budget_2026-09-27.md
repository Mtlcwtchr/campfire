# Bounded world placement — 2026-09-27

Продолжение `recursive_forest_proxies_2026-09-27.md`: ограничен именно
placement pipeline, который в предыдущем стресс-прогоне запросил 172 507
регионов. Это не завершение дальней иерархии леса и не общий лимит памяти мира.

## Лимиты по умолчанию

| Работа / резидентность | Предел |
|---|---:|
| Видимые ownership-регионы в admitted demand | 512 |
| Проверенные узлы дерева за visibility query | 8192 |
| Дополнительные тёплые регионы CPU-кэша | 128 |
| Новые регионы, запущенные за update | 32 |
| Регионы в одном worker batch | 8 |
| Собранные результаты за update | 8 |
| Новые опубликованные регионы за incremental update | 8 |
| Одновременные workers | 1–4, как прежде |

`SceneRegionBudget` и `ScenePlacement::Limits` доступны вызывающему коду.
Лимиты считаются на вызов update; игровой pass вызывает его один раз при
подготовке density/scene snapshot. Каждый регион — 128×128 м, максимум 256
scatter-кандидатов. Резидентный snapshot поэтому ограничен и по размеру
массива объектов; region cache после update содержит не более 640 регионов.
Временные результаты worker и удержанные внешними читателями snapshot leases
учитываются отдельно, а не выдаются за часть лимита кэша.

## Что изменено

- `scene_view.hpp`: best-first обход по нижней оценке расстояния до региона,
  без предварительного перечисления/сортировки всего видимого мира. И число
  результатов, и число посещённых узлов ограничены. Сохраняются frustum,
  crown padding и pixel-floor проверки; равные расстояния имеют стабильный порядок.
- `scene_placement.cpp/.hpp`: принимается ограниченный приоритетный префикс
  входа. Отложенный хвост не превращается в бесконечную очередь. Кэш закрепляет
  только admitted demand, а не весь видимый мир.
- Завершённые batch-результаты разбираются порциями. Полностью покинутые
  задания отменяются между регионами; ecology revision проверяется перед приёмом.
- Published residency отделена от готового кэша: возвращение камеры в тёплый
  набор тоже публикуется порционно. Старые immutable leases, stable object IDs,
  `objectsVersion` и региональные ecology revisions сохраняются.
- Прямоугольный compatibility API остаётся атомарным и ограниченным по числу
  регионов; превышение его лимита возвращает явную ошибку, а не неполный прямоугольник.
- `scene_models_pass.cpp/.hpp`: bounded query подключён к runtime;
  JSON/debug-вывод показывает cache/in-flight/start/collect/publish и query limits.

`complete` теперь явно означает готовность **принятого набора**. Это не обещание
полноты видимого мира. `capacityLimited` сообщает об урезанном входе placement;
`placement_budget_limited` в renderer также учитывает остановку visibility query.

## Исправление приоритета карты

Первый headless-прогон показал ошибку, ранее скрытую полным перечислением:
`ViewState::position` в ортографическом режиме — условный глаз, который при
zoom 0.02 отстоит от фокуса на многие километры. Безусловный `predictedPosition()`
направлял ограниченный запрос не к центру карты; все 1510 объектов того прогона
оказались вне экрана.

`SceneView::predictPriority` теперь сохраняет заданный фокус для ортографической
камеры. Предсказание положения глаза применяется только в перспективе.
Добавлена регрессия с настоящим `Camera::viewState`, включая velocity/lookahead.

## Реальный дальний прогон

Metal headless, seed 11, world small (238×238), map, координаты 16000,44550,
zoom 0.02, 640×400, screenshot на **frame 1200**.

После исправления приоритета прогон завершён. На всех десяти debug-отметках
(frame 120–1200): **512/512 регионов**, `complete=1`, `placement-limited=1`,
**1122 посещённых узла**, **512 регионов в кэше**, **9401 выбранный объект**.
К этим отметкам очередь уже пуста. В конце работали **8 forest proxies**;
новая схема не отключает их ради прохождения стресс-теста.

Повторный прогон финальной обычной сборки также завершился на frame 1200:
9401 объектов, 0 вне экрана. Все десять диагностических отметок автоматически
сверены с лимитами; итоговый JSON извлечён из лога.

Это подтверждение ограниченности данного placement-сценария, **не steady-state
A/B и не доказательство ускорения при прежнем качестве**. Отдельные объекты
за приоритетным пределом сейчас намеренно не загружаются. Terrain/grass пути
не изменены, но они не заменяют полноценную дальнюю иерархию леса.

Артефакты: `.cache/placement-budget-20260927/`, в частности
`far-1200-fixed.log`, `far-1200-fixed.json`, `far-1200-fixed.png`,
`far-1200-release.png`, `ctest-final.log`, `ctest-diagnostic.log`, `sanitizers.log`.
