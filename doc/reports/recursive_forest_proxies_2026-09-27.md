# Runtime forest proxies и bounded cache — 2026-09-27

Продолжение hemisphere/depth этапа. Это первый работающий runtime-уровень
пространственных proxy, не завершение всей многоуровневой системы леса.

## Модули

- `Campfire::Impostors` (`asr_impostors`): CPU atlas, recursive baker,
  неблокирующий cache с одним одновременно работающим worker. Нет SDL/game/content.
- `Campfire::ImpostorsGPU`: fixed-slot texture arrays, ограниченная публикация
  слоёв, одноразовое чтение входных PNG при открытии каталога.
- `ForestProxyCache` — игровой адаптер к ScenePlacementSnapshot; сам baker
  не знает ни WorldMapData, ни биомов, ни каталога игровых моделей.

## Рекурсивное запекание

Вход — hemisphere color/normal/depth atlas реальных членов с их позициями,
scale, yaw и tint. Малые группы превращаются в промежуточные proxy, затем
объединяются в корень. Исходные треугольники в runtime bake не обходятся.

Depth-texels восстанавливаются в 3D и проецируются в родительские 21 вида.
Окклюзия выбирается по глубине, одинаковая глубина разрешается детерминированно.
Границы охватывают полные сферы детей. Ошибка накапливается по уровням, учитывает
дискретность ракурсов/texels; цветовые и нормальные mipmaps строятся с coverage.
Это аппроксимация single-depth surfaces, не восстановление скрытой геометрии.

В игровом пути кэшируются корни групп **32 м**, для которых есть 6–64
поддерживаемых растений. Промежуточные рекурсивные atlas живут в worker и
освобождаются после bake. Отдельная мировая иерархия 32→128→512 м ещё не добавлена.

## Резидентность и замена

- Восемь слотов, бюджет CPU-кэша **результатов** 16 MiB. Leaf sources и временная
  память одного worker учитываются отдельно; все размеры ограничены options.
- GPU: 8×21 слоёв по 64×64; color/normal с mips, depth без mips,
  около **9.625 MiB**. CPU leaf sources растений — примерно 12 MiB.
- За кадр отправляется не больше **одного вида, 60 072 байта** с mipmaps.
  До отправки всех 21 видов слот не отдаёт право замены объектов.
- Повторные заявки дедуплицируются. Revision/ticket не позволяет старому worker
  опубликоваться после редактирования или ухода региона. Ошибки не ребейкаются
  бесконечно каждый кадр. Grace period — 0.75 секунды.
- Последний submission защищает и draw, и частичные GPU-copy. Slot reuse
  запрещён до завершения соответствующего fence. Cycling всего общего atlas нет.
- Shared RepresentationSelector проверяет экранную/угловую/parallax ошибку
  и оценку стоимости. Очередь отдаёт приоритет достижимым допускам, а не только
  количеству членов. На быстрых маршрутах часть bake так и не успевает использоваться.
- Замена — атомарный complete cut с гистерезисом, **не** новый temporal crossfade.
  До готовности proxy остаются исходные объекты. Неподдерживаемые модели не скрываются.
- Proxy не пересекается с опубликованной terrain density-заменой. Full-region
  mass mesh временно уступает отдельным объектам там, где выбран дочерний proxy.
- Отдельный instanced batch использует существующий quad/instance arena и 64-байтовый ABI.
  Ветер группы заморожен, это учтено запасом ошибки; лес не деформируется как одно дерево.

## Исправление packed PNG

На реальных ресурсах найдено повреждение данных: generic `IMG_Load` на macOS
менял RGB полупрозрачных texels. Например, B=1 превращался в 0 при A=123;
упакованные RG16 глубины также нельзя пропускать через premultiplication.

Добавлены `Device::loadDataPng/loadDataArray`: публичный `IMG_LoadPNG_IO`
с гарантированным STB backend. Байтово-точный путь используется для CPU input
и существующего индивидуального hemisphere depth-atlas. Ordinary colour
текстуры террейна, его маски переходов и параметры теней не менялись.
Регрессия сравнивает все RGBA-байты PNG с alpha 0/67/123/255 на CPU и GPU.

## Проверки и реальные прогоны

- CPU-модули: **52/52**, включая рекурсию, трансформы, tint, depth ordering,
  cancellation, budget rejection, revision race, partial publication и fence retirement.
- Целевые GPU-регрессии: **10/10** — packed PNG, bounded upload, hemisphere,
  прежние маски материалов, склоны и мягкие тени.
- CTest `engine_modules`, `engine_viewport_gpu`, `impostor_depth_baker`: **3/3**.
- CPU-only модуль собран штатным CMake без SDL/DXC. Клиент и тесты окончательно
  пересобраны целиком из собственных C++ единиц (171 команда); готовые сторонние
  библиотеки переиспользованы, LLVM/DXC не пересобирались.
- На дальнем статичном виде зафиксированы до **8 одновременно выбранных proxy**.
  В завершённом коротком screenshot-прогоне: 31 bake, 293 загруженных вида,
  492 накопленных кадровых proxy submissions на последней debug-отметке.
  Снимок записан на frame 400, seed 11, map, zoom 0.02, 640×400.
- Полный CTest, ручной визуальный аудит и новый Instruments trace не выполнялись.

## Производительность и незавершённое

Камера 640×400, 480 загрузочных кадров + по 180 на сегмент:

| Сегмент | Proxy ON mean/max, мс | Proxy OFF mean/max, мс |
|---|---:|---:|
| map-far | 8.63 / 128.26 | 9.20 / 47.63 |
| orbit | 18.46 / 96.56 | 21.62 / 50.39 |
| forest | 11.22 / 61.47 | 13.37 / 32.57 |
| flight | 15.03 / 43.10 | 19.58 / 84.16 |
| zoom-out | 17.13 / 46.74 | 25.02 / 44.63 |

Это разные стримящиеся прогоны с разным готовым набором геометрии, не
steady-state A/B. ON включал debug-счётчики. Ускорение и устранение спайков
**не доказаны**; большие пики остаются. На этом движущемся маршруте proxy
не доходили до использования, в отличие от стационарного дальнего вида.

Стресс-снимок на 1200 кадров был остановлен: существующий world-streaming
запросил около **172 507 регионов**, в процессе вырос до >100 тысяч выбранных
объектов и сотен миллисекунд на кадр. Это не bounded-сценарий для всего мира;
ограничен новый atlas cache, а не существующий placement pipeline. Короткий
снимок на 400 кадров и контроль меньшего охвата завершились успешно.

Следующие задачи: бюджет запросов/публикации world placement, предсказание
потребности proxy, кэш промежуточных узлов и крупные масштабы леса, затем
общий hierarchical traversal и плавный переход proxy/children.

Отключение нового пути: `ASR_FOREST_PROXIES=0`; счётчики: `ASR_SCENE_DEBUG=1`.
