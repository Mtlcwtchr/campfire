## Реализованный слой теней

- Отдельный `ShadowClipmap`, не зависящий от готовых render meshes и их LOD.
- Источник: heightfield, детерминированный scatter и один immutable снимок ecological delta.
- Локальные light-space уровни 128 / 512 / 2048 / 8192 м, по 128×128 texels.
  Четыре канала: непрозрачный объект, крона, optical depth, terrain depth.
  GPU-кэш — 1 МиБ, не карта всего мира.
- Непрозрачные объёмы стволов/камней, несколько объёмов кроны,
  экспоненциальная трансмиссия листвы; размеры берутся из canonical catalogue metadata.
- Дальние уровни используют heightfield и агрегированную высоту/плотность полога.
- Один worker; максимум один завершённый shadow upload на кадр.
  Поворот света и события в пересекающихся регионах инвалидируют кэш;
  результат от устаревшей ревизии не публикуется.
- Земля, scene models и трава принимают одинаковые тени.
  Уменьшается прямой свет, не ambient. Для terrain и объектов разные depth bias.
- Внутри уровня читаются четыре PCF texels, соседний уровень — только на переходе.
- Направление задаёт `WorldRenderSettings::sunDirection`; `CAMPFIRE_NO_SHADOWS=1`
  предназначен для A/B-проверки, не является оптимизацией по умолчанию.

Это **первый работающий слой**, а не полная реализация целевого shadow DOCX:
канонические деревья пока представлены приближёнными объёмами, без импортированного
branch skeleton; нет structural building sources, skinned dynamic casters,
направленного horizon cache, PCSS и обновления только вошедших полос внутри уровня.
Перестраивается один локальный уровень, а не весь мир. При солнце ниже порога z=0.12
текущий shadow cache отключается. Поддержку низкого солнца надо расширить отдельно.

## Экология → представление → кластеры

- 64-метровые ecology cells, отдельные potential/current canopy, grass/shrubs,
  deadwood, moisture, fertility, wetland, disturbance, succession и habitat masks.
- Классификатор содержит 26 названий биомов из документа; biome enum не источник
  физического состояния и не заменяет правила размещения.
- Существующие поля влажности, плодородия почвы, дренажа, сезонности и пойменного
  потенциала читаются напрямую, с билинейной интерполяцией и проверенной шкалой 0–255.
  Soil depth, groundwater и salinity пока приближённые, это не новая гидросимуляция.
- Деревья, кусты, грибы, камни и валежник материализуются из текущего состояния.
  Одни и те же кандидаты сохраняют стабильные ID при разных запросах/порядке workers.
- `ecology::Store` хранит copy-on-write исключения ячеек и удалённых объектов.
  `set` / `remove` меняют ревизию соответствующего 128-метрового ownership region.
- `ScenePlacement` выбрасывает устаревшие jobs/cache entries, не соседние регионы.
  Snapshot передаёт region revisions кластерному проходу.
- Mass-бейки проверяют ревизию перед публикацией. Неизменённые regions сохраняют
  geometry, measured errors и refusal cache вместо повторного запекания.

Граница реализации ecology DOCX: календарное выполнение succession, сохранение delta
на диск, полноценные resource patches/животные/аграрные действия, новые species assets,
пространственный gradient ForestEdge и сквозное изменение GPU grass/climate textures
ещё не подключены. Маски и функция редкого succession update имеются как world API.
Это не завершённая симуляция всей описанной экосистемы.

## Измерения и оптимизации

Внешний Time Profiler, без новых RAII-зон/SDK в движке:

- Baseline: `MacroWorld::attach` — 11.6% self sampled CPU по всем потокам.
  Теперь один HeightField принадлежит всему worker batch, а не каждому региону.
- На main thread `ScenePlacement::updateRegions` занимал 37.18% inclusive sampled CPU.
  Hot lookups переведены с деревьев на hash-таблицы. Публикация по-прежнему
  детерминирована: regions и Object::id сортируются в момент публикации.
- Frustum planes и distance sort keys вычисляются один раз, не в каждом сравнении.
- Проверка ecological dirty cache выполняется только при новой ревизии.
- Массив объектов резервируется заранее; тёплый fringe отбирается через nth_element.
- Mass-bake concurrency ограничен 1–2 workers, приём aggregate/upload — один на кадр.
- Shadow sampling сокращён с четырёх уровней на каждом пикселе до одного в интерьере.
- Финальный attach-профиль обнаружил дополнительные расходы publication metadata:
  demand теперь переносится через move; таблица region revisions — резервируемая
  hash-таблица; отдельный `objectsVersion` предотвращает повторные ECS/gather/mass
  обновления, если object payload точно равен прежнему.

### Маршрут

`--explore --seed 11 --headless 960x600 --bench 60 --bench-load 120`.
Значения — wall-time кадров, **не GPU timestamps**. `Runner::cpu()` не включает
всю работу `prepareDensity` до входа в runner, поэтому нельзя приписывать всю
разницу wall/CPU видеокарте.

| Сегмент | Первая версия с тенями: mean / p99, мс | Промежуточный повтор 2 | Промежуточный повтор 3 |
|---|---:|---:|---:|
| orbit | 39.37 / 67.49 | 29.06 / 66.22 | 27.91 / 57.73 |
| forest | 31.62 / 44.92 | 24.79 / 46.16 | 17.08 / 27.71 |
| flight | 35.04 / 47.45 | 20.96 / 32.92 | 17.86 / 27.41 |
| zoom-out | 59.99 / 107.87 | 37.61 / 58.93 | 37.79 / 78.80 |

Первый zoom-out max был 141.44 мс; последние два — 64.21 и 96.18 мс.
Это уменьшение спайков, **не их полное устранение**. 60 FPS/16.7 мс ещё не выдерживаются.
После заключительной оптимизации публикаций чистый короткий прогон дал:

| Сегмент | mean, мс | p99, мс | max, мс |
|---|---:|---:|---:|
| orbit | 24.80 | 48.48 | 56.89 |
| forest | 13.96 | 21.78 | 23.89 |
| flight | 16.10 | 25.62 | 28.33 |
| zoom-out | 26.34 | 40.88 | 43.53 |

Маршрут короткий, streaming не успевает стать settled во всех сегментах; это проверка
переходов/дозагрузки, не статистически строгий steady-state benchmark.
Исходный baseline до экологии/теней сохранён, но смена ecology меняет состав сцены,
поэтому его нельзя считать чистым A/B только одной оптимизации.

Один контрольный и первый повторный прогон пересеклись с внешней Unreal-компиляцией
`ASTerrainSubsystem.cpp`; там были пики 200–900 мс. Эти результаты сохранены,
но исключены из таблицы. Чужие процессы не останавливались.

Одна запись xctrace дошла до `Recording completed. Saving output file...`, но процесс
не завершился за timeout; metadata корректно помечает её failed, не успешной записью.
Повтор через attach к прогретому процессу **успешен**: native trace, `report.html`
и `summary.json` в `.cache/profiles/shadows-ecology-20260926-attach/`.
Именно эта запись использована для последней оптимизации публикаций; итоговые frame
timings измерены отдельно, без Instruments. Более длинный маршрут под Instruments
давал отдельные пики до 285 мс, поэтому короткая таблица не является гарантией
отсутствия спайков при длительном стриминге.

Заключительный длинный прогон **без Instruments**, 180 кадров на сегмент,
240 кадров загрузки: mean / p99 / max (мс) — orbit 22.50 / 43.08 / 86.89,
forest 22.60 / 50.58 / 63.65, flight 24.89 / 39.60 / 87.69,
zoom-out 25.27 / 42.34 / 67.51. Остаточные пики требуют дальнейшей работы,
не скрываются усреднением или отключением теней.
