# Спецификация control map террейна

Control map задаёт непрерывные поля управления для импорта мира. Импортер читает значения каналов по их именам в `world.json`; для упрощённого импорта одиночной картинки применяется фиксированный порядок RGBA, описанный ниже.

## Одиночная RGBA-карта

Для импорта через `worldtool import-images` (или соответствующую команду редактора) подготовьте PNG формата RGBA, 8 бит на канал. Каждый пиксель соответствует точке карты; изображение растягивается на прямоугольник назначения. Размер можно выбрать под нужную детализацию. Если ширина и высота совпадают с числом точек террейна в прямоугольнике, данные попадут в сетку напрямую; иначе непрерывные поля пересчитываются билинейно.

| Канал | Имя в схеме | Значение 0 | Значение 255 | Начальное значение |
|---|---|---|---|---|
| R | `moisture_bias` | минимум влаги | максимум влаги | 128 (≈0,5) |
| G | `forest_bias` | минимум лесного влияния | максимум лесного влияния | 128 (≈0,5) |
| B | `mountain_strength` | влияние выключено | максимальное влияние | 0 |
| A | `erosion_strength` | эрозия выключена | максимальная сила эрозии | 128 (≈0,5) |

Значения линейные: `0` соответствует 0, `255` — 1. Не применяйте цветокоррекцию, гамму, цветовой профиль или преобразование sRGB к данным каналам. Каналы не являются цветом и должны редактироваться как числовые маски. Без карты используются начальные значения из таблицы.

Ось X идёт слева направо. Верхний Вряд изображения соответствует северной (верхней) стороне прямоугольника импорта, нижний — южной. Импорт прямоугольника сдвигает и растягивает изображение на выбранную область мира.

## Пакет мира (`world.json`)

Для пакетного импорта положите растр, например, в `raster/control_0.png` и объявите его в `world.json` как растр вида `control` с типом `rgba8`. Описание каналов задаёт семантику каждого компонента PNG, поэтому названия в манифесте обязательны. Порядок можно менять, если одновременно правильно сопоставить каналы `R`, `G`, `B`, `A`.

```json
{
  "file": "raster/control_0.png",
  "type": "rgba8",
  "kind": "control",
  "channels": {
    "R": { "name": "moisture_bias", "range": [0, 1], "default": 0.5, "interpolation": "bilinear", "optional": true, "version": 1, "affects": ["climate", "ecology"] },
    "G": { "name": "forest_bias", "range": [0, 1], "default": 0.5, "interpolation": "bilinear", "optional": true, "version": 1, "affects": ["ecology", "vegetation"] },
    "B": { "name": "mountain_strength", "range": [0, 1], "default": 0, "interpolation": "bilinear", "optional": true, "version": 1, "affects": ["terrain", "drainage"] },
    "A": { "name": "erosion_strength", "range": [0, 1], "default": 0.5, "interpolation": "bilinear", "optional": true, "version": 1, "affects": ["terrain"] }
  }
}
```

В пакете каждый канал может иметь 8- или 16-битное представление PNG; для обычной RGBA-карты используйте 8 бит. Диапазон `[min, max]` в `world.json` задаёт перевод сохранённого числа в значение поля. Неизвестные импортеру control-каналы могут храниться в источнике, но игровые системы используют только каналы с распознаваемыми именами.

## Значение полей в террейне

- `moisture_bias` управляет влажностью/осадками: 0 и 1 — края диапазона, 0,5 — нейтральное значение.
- `forest_bias` задаёт локальное смещение густоты леса; итог также зависит от биома, категории грунта и других полей.
- `mountain_strength` задаёт силу горного воздействия в генерации/обработке террейна. Ноль отключает это воздействие.
- `erosion_strength` задаёт, насколько сильно к этому месту применяется эрозия. Ноль защищает от этого воздействия, 1 включает полную силу.

Эти карты задают управляющие коэффициенты, а не готовые текстуры, категории поверхности, высоты или границы биомов. Переходы желательно рисовать плавно: при несовпадении размера с целевой сеткой значения будут интерполироваться.

## Проверка перед импортом

- PNG не индексированный и не черно-белый: для одиночной карты нужны именно четыре канала RGBA.
- Размеры и пропорции соответствуют прямоугольнику мира, в который выполняется импорт.
- В альфа-канале действительно находится `erosion_strength`, а не прозрачность.
- В экспортёре/редакторе отключены гамма-коррекция и цветовые преобразования.
- Для пакета имена каналов и их порядок в `world.json` соответствуют PNG.

Реализация канонической схемы и одиночного импорта находится в `src/engine/world_source/transfer.cpp` (`canonicalSchema`, `importImages`); чтение игровых полей по имени — в `src/game/generation/world_import.cpp`.
