# Региональная детализация: проверка готовности и бюджета

Дата: 2026-09-14. Проверен текущий рабочий renderer на macOS / Metal.
Это отчёт о продолжении реализации, не утверждение о завершении отдельной
геометрии всех рек, берегов и вертикальных клифов.

## Исправления

- `TerrainPlanner::finish` рассчитывает цели региональной готовности после
  объединения параллельных этапов, по уже построенным целевым мешам.
  Предиктивный этап использует только грубую поверхность: её ошибка не должна
  определять окончательную готовность меша с другим источником и шагом.
- Запрос готовности не строит будущие детальные меши. Для ещё не построенных
  участков сохраняется предварительная оценка. Полное покрытие цели и
  родительский морфинг продолжают учитываться; замены проверки только
  видимыми треугольниками нет.
- `waterPageSurfaceVertex` проверяет только бит 0 юбки. Флаги сшитой границы
  и явных высот больше не обнуляют покрытие воды обычной вершины.
- Добавлены CPU-проверки неровного регионального рельефа и поэтапной
  публикации H64 → H16 → H8: незагруженные данные не дают 100%, а полные H4
  не требуются. Сохранены проверки обычной политики с H4.

## Границы проверки

- Лимит 65536 ограничивает удерживаемые отсчёты, но не суммарную работу
  построения: за загрузку вычисляется более миллиона feature-отсчётов.
- Около 600 тысяч треугольников земли остаются существенным бюджетом.
  Эти прогоны не доказывают ускорение FPS относительно прежнего renderer.
- Целевые высоты сейчас входят в адаптивный heightfield. Это не отдельные
  явные линии перелома и не меш вертикальной стенки клифа.
- `WaterPagePS` по-прежнему получает fragment depth, cover и motion из
  `pageDetail`. Исправление бита юбки само по себе не доказывает сохранение
  каждого узкого русла целевой геометрии после фрагментного clipping.
- GPU-набор проверяет компиляцию и численные пути, но не заменяет визуальную
  приёмку берегов, русел и клифов в движении камеры.
